
# The Mystery Adventure 🐯

A beginner-friendly Python text adventure game.

## Features
- Choose your adventure path
- Discover hidden treasure
- Fight a dangerous tiger
- Manage your health
- Escape from enemies
- Play Again option

## Technologies
- Python 3

## How to Run

1. Clone this repository.
2. Open the project.
3. Run game.py.
